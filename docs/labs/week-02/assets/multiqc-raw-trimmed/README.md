The two figures are static exports from the report's native Plotly 3.1.2 plots:

- `fastqc_per_base_sequence_quality_plot`: all eight raw/trimmed FastQC mean-quality curves.
- `fastqc_adapter_content_plot`: all 13 adapter/polyA/polyG curves displayed in the report. The report hides 35 other sample–adapter combinations below its 0.1% threshold; their absence must not be interpreted as exact zero.

Data points are unchanged; no smoothing, resampling, or averaging of the original curves was added. The `figure-data.json` file preserves the original selected plot definitions, source IDs, data arrays, and native display settings, as well as the fastp read-retention figures used in the lab explanation.

Display changes for both exports: shorter sample labels, visible legends, dashed raw curves and solid trimmed curves, explicit axis labels, white background, larger fonts, and fixed export dimensions. Original FastQC background quality/status bands remain visible. The quality plot uses a Q30–38 y-axis to show small differences; all source quality means lie within that range. Its curves are colored by library and mate to make raw/trimmed comparisons possible (the source report colors all eight green because all pass that module). The adapter plot retains its native trace colors and uses a 0–10% y-axis; `adapter` in its legend means `illumina_universal_adapter`.

Label mapping: `fastqc | SRX13548510_SRR17374239_1/2` → BGISEQ R1/R2 raw; `fastqc | SRX23612877_SRR27956204_1/2` → Illumina R1/R2 raw; `fastqc_trimmed | bgiseq_1/2` and `fastqc_trimmed | illumina_1/2` → the corresponding trimmed mates. The BGISEQ library is genomic DNA; the Illumina library is RNA-seq. Separate library preparation and sequencing differences mean these figures do not isolate a platform effect.

Adapter content is cumulative: it counts reads in which a configured sequence has been seen by that position. PolyA/polyG sequence matches are distinct from the Illumina universal adapter. See [FastQC's adapter-content explanation](https://www.bioinformatics.babraham.ac.uk/projects/fastqc/Help/3%20Analysis%20Modules/10%20Adapter%20Content.html).
