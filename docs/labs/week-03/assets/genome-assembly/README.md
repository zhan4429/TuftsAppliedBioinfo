# Week 3 Session 1 figures

These original course figures are generated by `tools/plot_assembly_figures.py`
with matplotlib. PNG files are embedded in the lab; SVG files are available for
enlargement. No student needs to install matplotlib or run this script.

## two-assembly-routes

A teaching diagram of the two routes in the current lab. Both use the same HiFi
input and hifiasm; the pipeline repeats preprocessing with fastplong and runs QUAST
and BUSCO. The diagram is not a trace of an actual Nextflow execution.

- https://github.com/nf-core/genomeassembler/blob/2.0.1/modules/nf-core/hifiasm/main.nf
- https://github.com/nf-core/genomeassembler/blob/2.0.1/conf/modules/assembly.config

## n50-worked-example

A synthetic example, not the yeast assembly: contig lengths of 5, 3, 2, 1 and 1 Mb.
The total is 12 Mb, with a halfway point of 6 Mb. The first two sorted contigs sum
to 8 Mb; N50 is 3 Mb and L50 is 2 contigs. Bar widths use the same linear scale.

## observed-assembly-size-gc

Measured inputs were supplied by the instructor in the course editing
conversation on November 13, 2026. They describe the full-read hifiasm
0.25.0-r726 assembly of the lab's HiFi run, SRR18210286:

| SeqKit summary | Contigs | Length (bp) | GC (%) |
|---|---:|---:|---:|
| `seqkit stats -a asm.p_ctg.fa` | 134 | 17,499,613 | 35.57 |
| `seqkit seq -m 100000 asm.p_ctg.fa` followed by `seqkit stats -a` | 25 | 13,298,638 | 38.84 |

The short group is obtained by subtraction: 109 contigs and 4,200,975 bp.
Its approximate GC is calculated as:

```text
(17,499,613 × 35.57 − 13,298,638 × 38.84) / 4,200,975 ≈ 25.2%
```

The two reported GC percentages are rounded, so the derived percentage is an
estimate. The figure has no simulated coverage values or contig assignments.
The 12.1 Mb reference line is the expected size used in the lab. The 100 kb split
is diagnostic, not a recommended filtering rule or a biological classification.
