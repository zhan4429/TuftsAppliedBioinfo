Available Labs

Course labs

Open these labs during class. They are organized for reading, copying commands, checking expected outputs, and revisiting answers after trying each question.

Session 1 Command Line, Text Processing, and Git Use Tufts HPC, inspect a GFF3 file, practice shell pipelines, and create a homework Git repository. Session 2 HPC, Environments, and Fetching Public Data Request compute resources, submit SLURM jobs, test containers, and start an nf-core/fetchngs download.

Using the Repository

Keep your copy current

Clone once, then pull before each class. Large data and generated results should stay on Pax or course storage, not in GitHub. 

git clone <repository-url>
cd <repository-name>
git pull
