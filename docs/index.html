Week Topics Labs
0 Optional preparation

Self-paced practice with shell navigation and basic Python or R syntax.
1 Command line, HPC, and reproducible environments

Linux command line, text processing, Git/GitHub basics, HPC job submission with SLURM, conda/mamba environments, containers, public databases, and dataset inspection.
  • Session 1Command Line, Text Processing, and Git
  • Session 2HPC, Environments, and Fetching Public Data
2 Sequencing design and quality control

Sequencing technologies, experimental design, replication, confounding, batch effects, FASTQ format, FastQC, fastp, MultiQC, and QC interpretation.
  • Session 1QC Across Four Sequencing Platforms
  • Session 2Trimming, Filtering, and Reading QC Across Samples
3 Genome assembly and annotation

Assembly QC, contamination screening, GFF3/GTF structure, functional annotation, annotation version issues, and IGV inspection.
  • Session 1Assembling a Genome
  • Session 2Annotation, and What Counts as Evidence
4 Read alignment and variant calling

SAM/BAM processing, alignment QC, variant calling with GATK HaplotypeCaller and DeepVariant, filtering, benchmarking, annotation, and VCF interpretation.
5 Bulk RNA-seq quantification

RNA-seq design, pseudoalignment, alignment-based quantification, library type and strandedness, nf-core/rnaseq, count matrices, metadata, and exploratory analysis.
6 Differential expression

DESeq2, design formulas, covariates and batch effects, multiple testing, visualization, enrichment analysis, and notebook/report preparation.
7 Chromatin accessibility and binding

ATAC-seq, peak calling with MACS3, nf-core/atacseq, ChIP-seq and CUT&RUN/CUT&Tag concepts, QC metrics, peak annotation, motif enrichment, and integration with expression results.
8 Single-cell RNA-seq preprocessing

10x barcodes and UMIs, Cell Ranger, STARsolo, alevin-fry, nf-core/scrnaseq, AnnData and Seurat objects, QC, filtering, normalization, and feature selection.
9 Single-cell analysis and spatial transcriptomics

Dimensionality reduction, clustering, marker genes, cell type annotation, batch integration, pseudobulk differential expression, and spatial transcriptomics.
10 Microbiome and metagenomics

16S amplicon workflows, QIIME2/DADA2, compositional data, shotgun taxonomic and functional profiling, metagenome-assembled genomes, diversity metrics, and differential abundance.
11 Mini-project preparation

Dataset acquisition and QC as assigned.
12–14 Mini-project

Reproduce key findings from a published paper, maintain a reproducible GitHub repository, prepare notebooks and reports, and present results.

Setup and tutorials

Get the course repository

Clone the repository once on Pax:

git clone https://github.com/zhan4429/TuftsAppliedBioinfo.git

Then pull before each class to get the latest labs:

cd TuftsAppliedBioinfo
git pull

Keep large data and generated results on Pax or course storage, not in GitHub.

Course expectations

Reproducible work

Bioinformatics work should be understandable and rerunnable by someone else, including your future self. A pipeline result is not automatically correct because it ran successfully.

  • Keep commands, parameters, sample IDs, and software versions visible.
  • Use relative paths when possible.
  • Separate raw data, intermediate files, final outputs, and reports.
  • Document where input data came from.
  • Preserve small configuration files and sample sheets.
  • Avoid committing large generated files unless instructed.
  • Record failed or unexpected results when they affect interpretation.

Using AI assistants

AI coding assistants are permitted and expected as part of the course, but they do not replace scientific judgment.

  • Disclose AI use in submitted notebooks or reports, including the tool used and what it helped with.
  • Verify generated commands and code against documentation, error messages, and expected outputs.
  • You are responsible for every line you submit.
  • Written interpretation, discussion, and limitations sections should be your own scientific reasoning.
  • Watch for hallucinated arguments, deprecated APIs, plausible but inappropriate statistical choices, and code that runs while producing the wrong analysis.
