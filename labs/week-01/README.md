# Week 1 Labs

Week 1 introduces the computational habits used throughout Applied Bioinformatics: command-line work, Git, HPC job submission, reproducible environments, containers, Nextflow, nf-core, and public data access.

## Sessions

1. [Command Line, Text Processing, and Git](01-command-line-git.md)
2. [HPC, Environments, and Fetching Public Data](02-hpc-environments-fetchngs.md)

## Before Class

Make sure you can access Pax through OnDemand or SSH. You do not need prior command-line experience, but you should be ready to copy commands carefully, read outputs, and ask questions when the output differs from the lab.

## Data and Outputs

Large data and generated results should stay on Pax or in course-provided storage. Do not commit FASTQ, BAM, large workflow outputs, credentials, or private data to GitHub.
